3. Activity Diagram — Complaint Resolution Lifecycle

flowchart TD
    Start([Customer Submits Complaint]) --> Validate{Valid and Non Duplicate?}
    Validate -->|No| Reject[Return Validation Error]
    Reject --> End1([End])
    Validate -->|Yes| Preprocess[Pre-process: Sanitize and Normalize]
    Preprocess --> DupCheck{Near Duplicate or Repeat?}
    DupCheck -->|Yes flagged| FlagRepeat[Flag is_repeat is_near_duplicate]
    DupCheck -->|No| Store[Store Complaint - Status New]
    FlagRepeat --> Store

    Store --> RunP1[Run Pipeline 1: GenAI Analysis]
    RunP1 --> RetrieveKB[Retrieve Active KB Chunks plus Rule Context]
    RetrieveKB --> CallGenAI[Call Anthropic API]
    CallGenAI --> ValidJSON{Valid JSON Schema?}
    ValidJSON -->|No retry available| Retry[Retry with Stricter Prompt]
    Retry --> CallGenAI
    ValidJSON -->|No retries exhausted| FailP1[pipeline1_status = failed]
    FailP1 --> ManualQueue
    ValidJSON -->|Yes| StoreP1[Store GenAI Result]

    StoreP1 --> RunP2[Run Pipeline 2: Python Validation]
    RunP2 --> RunValidators[Run 12 Deterministic Validators]
    RunValidators --> Compare[Comparison Engine: Compute Verification Score]
    Compare --> Decision{Escalation Required per Rules?}
    Decision -->|Yes GenAI said No| Override[Python Overrides: Force Escalation]
    Decision -->|Matches or No Escalation| CheckScore{Score 85 or above AND No Flags?}
    Override --> CheckScore

    CheckScore -->|Yes| Verified[Status: Verified]
    CheckScore -->|No| ManualQueue[Route to Manual Review Queue]

    ManualQueue --> ReviewerAction[Reviewer: Approve Modify Reclassify Escalate]
    ReviewerAction --> AuditLog[Log Original plus Final Values to Audit Trail]
    AuditLog --> Finalize[Finalize Resolution]

    Verified --> Finalize
    Finalize --> Respond[Send Professional Response to Customer]
    Respond --> FollowUp{Follow Up Required?}
    FollowUp -->|Yes| ScheduleFollowUp[Schedule Follow Up]
    FollowUp -->|No| Resolved[Status: Resolved]
    ScheduleFollowUp --> Resolved
    Resolved --> Closed([Status: Closed])

4. Sequence Diagram — End-to-End Complaint Processing

sequenceDiagram
    actor Cust as Customer
    participant FE as React Frontend
    participant API as FastAPI Backend
    participant DB as Database
    participant KB as Knowledge Base Retriever
    participant RM as Rule Matrix Engine
    participant P1 as Pipeline 1 GenAI
    participant Anthropic as Anthropic API
    participant P2 as Pipeline 2 Validation
    participant CE as Comparison Engine
    actor Rev as Reviewer

    Cust->>FE: Fill complaint form and submit
    FE->>API: POST /complaints
    API->>API: Validate plus Pre-process plus Duplicate check
    API->>DB: Store complaint status New
    API-->>FE: 201 Created complaint_id
    FE-->>Cust: Show confirmation

    API->>P1: analyze_complaint BackgroundTask
    P1->>KB: retrieve_relevant_chunks query
    KB-->>P1: Active non expired chunks
    P1->>RM: match complaint_features
    RM-->>P1: Candidate rule context
    P1->>Anthropic: Send rendered prompt
    Anthropic-->>P1: Structured JSON response
    P1->>P1: Validate against Pydantic schema
    alt Invalid JSON
        P1->>Anthropic: Retry with stricter prompt
        Anthropic-->>P1: JSON response
    end
    P1->>DB: Store GenAI result pipeline1_status completed

    API->>P2: validate genai_result
    P2->>RM: Independently match features no LLM call
    RM-->>P2: Ground truth rule
    P2->>P2: Run 12 validators
    P2->>CE: compare_and_verify
    CE->>CE: Compute verification_score
    alt Escalation mismatch
        CE->>CE: Override escalation_required True
    end
    CE->>DB: Store VerificationReport final_status

    alt final_status Manual Review Required
        API->>Rev: Appears in reviewer queue
        Rev->>API: POST reviewer decision
        API->>DB: Store reviewer decision plus audit trail
    end

    API->>DB: Update complaint status
    FE->>API: GET complaints id
    API-->>FE: Final response plus status
    FE-->>Cust: Display professional response
